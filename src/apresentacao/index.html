Persistência dos veículos

Uma tabela no SQLite

A API cria a tabela vehicles no arquivo data/fasttruck.db. Cada cadastro ocupa uma linha.

Colunas e restrições da tabelasql/schema.sql
CREATE TABLE IF NOT EXISTS vehicles (
    id TEXT PRIMARY KEY,
    plate TEXT NOT NULL UNIQUE,
    brand TEXT NOT NULL,
    model TEXT NOT NULL,
    year TEXT NOT NULL,
    color TEXT NOT NULL,
    body TEXT NOT NULL DEFAULT '',
    axles TEXT NOT NULL DEFAULT '',
    fuel TEXT NOT NULL DEFAULT '',
    km INTEGER NOT NULL DEFAULT 0 CHECK (km >= 0),
    price REAL NOT NULL CHECK (price >= 0),
    customized TEXT NOT NULL DEFAULT 'sim' CHECK (customized IN ('sim', 'nao')),
    notes TEXT NOT NULL DEFAULT '',
    status TEXT NOT NULL CHECK (status IN ('Disponível', 'Reservado', 'Vendido'))
)

A placa é única. O banco rejeita preço e quilometragem negativos e limita os valores de status.

Regras antes de gravar

A API confere os dados

O Python normaliza a placa, exige campos essenciais e rejeita valores inválidos antes do INSERT ou UPDATE.

Regras de negócio · como o cadastro se comporta

Dados confiáveis desde a entrada.

As regras centrais são aplicadas pela API Python antes de gravar ou alterar um caminhão.

IDRegra
RN01Placa obrigatória nos padrões antigo ou Mercosul; letras são convertidas para maiúsculas.
RN02Placa única no banco, normalizada sem espaços ou hífen para comparação.
RN03Marca, modelo, ano, cor, status e valor anunciado são obrigatórios.
RN04Status permitido: Disponível, Reservado ou Vendido.
RN05Quilometragem e valor não podem ser negativos.
RN06Personalização é “sim” ou “não”; observações são opcionais.
RN07Editar mantém o ID e revalida os dados e a unicidade da placa.
RN08Excluir só acontece depois da confirmação na interface.
RN09O indicador de valor soma todos os veículos, qualquer que seja o status.
RN10Os dados de exemplo são inseridos uma vez; excluí-los não os recria.

Contexto de uso

O que assumimos e o que fica fora.

O módulo FasTruck permite cadastrar e gerenciar veículos, com dados persistidos no banco SQLite.

Premissas

  • Uma pessoa usa o sistema no computador local.
  • O painel é aberto pelo servidor Python, não como arquivo HTML.
  • O banco é `data/fasttruck.db`.
  • O banco contém 13 registros iniciais, que podem ser editados ou excluídos.
  • Personalizações são declaradas pelo operador, sem verificação externa.

Restrições

  • Sem login, perfis ou controle de acesso.
  • Sem backup automático ou sincronização entre dispositivos.
  • Sem consulta oficial de placa ou documentação.
  • Sem fotos, catálogo público, carrinho ou pagamentos.
  • Servidor de desenvolvimento local; não configurado para produção.
Riscos e respostas

Conhecer os limites do módulo.

Cada risco tem uma resposta dentro do escopo atual ou um limite claramente comunicado.

RiscoResposta nesta etapa
Perder ou danificar o arquivo SQLiteFazer cópias periódicas de `data/fasttruck.db`; não há backup automático.
Placa repetida com escrita diferenteNormalizar e validar a placa; banco também impede duplicidade.
Servidor parado ou banco indisponívelInterface informa falha de conexão e orienta a iniciar o Python.
Características ou personalização incorretasInformações são declaradas pelo operador e não verificadas.
Expor o servidor local na redeExecutar em `127.0.0.1`; o servidor está configurado para uso local.
Casos de uso · operador do estoque

Quatro jornadas do cadastro.

Os casos de uso descrevem o objetivo do operador, o caminho principal e as respostas a situações comuns.

UC01 · Cadastrar caminhão

Pré: servidor iniciado e banco acessível.
Fluxo: preencher dados → enviar → API valida → SQLite grava → lista e indicadores atualizam.
Alternativas: placa inválida ou repetida e falha de gravação mostram erro.

UC02 · Consultar estoque

Fluxo: abrir painel → carregar lista do banco → pesquisar placa, marca ou modelo → filtrar status.
Resultado: lista filtrada; indicadores continuam mostrando o total do estoque.

UC03 · Editar caminhão

Pré: veículo cadastrado.
Fluxo: abrir edição → alterar campos → revalidar → atualizar a mesma linha e atualizar a tela.
Alternativa: duplicidade de placa ou erro de conexão não confirma a edição.

UC04 · Excluir caminhão

Pré: veículo cadastrado.
Fluxo: solicitar exclusão → confirmar → API remove do SQLite → lista e indicadores atualizam.
Alternativa: cancelar, clicar fora ou pressionar Esc mantém o registro.
